# PokerNow Hand Alert 🂡

PokerNow 테이블에서 **내 홀카드 2장을 읽어**, 화면 위 **오버레이 패널(HUD)** 로
현재 패 · 프리미엄 여부 · 내 차례 · 스택/콜 정보(BB 단위)를 항상 보여주는 개인용 Chrome 확장입니다.

또한 **자동 폴드**(옵션, 기본 꺼짐)를 켜면 내가 지정한 핸드가 아닐 때
PokerNow 의 **미리 폴드(사전 액션)** 를 대신 눌러둡니다.
내가 취소하지 않으면 내 차례가 왔을 때 그대로 폴드됩니다.

> ⚠️ **자동 폴드는 기본으로 꺼져 있습니다.** 꺼져 있으면 게임 버튼을 자동으로
> 누르지 않고, Fold 는 내가 **직접**(오버레이 버튼 / `F` 키 / 팝업 버튼)
> 눌렀을 때만 실행됩니다. 켠 경우에도 **내 차례가 오기 전까지 언제든 취소**할 수
> 있습니다 (오버레이의 `취소` 버튼).
> 별도 서버 없이 100% 로컬, 외부 전송 없음.

---

## 1. 무엇을 하나요?

- 내 홀카드를 감지해 `AA` `AKs`(수딧) `AKo`(오프수딧) 처럼 정규화 (랭크: `2 3 4 5 6 7 8 9 T J Q K A`)
- **화면 오버레이 패널**에 항상 표시:
  - 현재 패 (예: `A♠ K♥` / `AKo`), ♥♦는 빨간색
  - **프리미엄 핸드**면 초록 강조 + 알림음
  - **내 포지션** (`BTN` `SB` `BB` `UTG` `HJ` `CO` …) 과 **지금 누구 차례인지**
  - **내 스택 / 이번 핸드에 낸 돈 / 지금 더 내야 하는 돈** 을 전부 **BB 단위**로 표시
  - **내 차례**면 남은 시간이 줄어드는 **타이머 바** (초록→노랑→빨강)
  - **콜 / 체크 · 폴드** 버튼 — 더 낼 돈이 `0 BB` 면 **체크만**, `0 BB` 초과면 **콜만** (둘이 같이 뜨지 않음)
  - 폴드해서 죽으면 카드를 지우고 `🃏 폴드함`
- **⧉ 팝아웃**: 패널을 Picture-in-Picture 창으로 빼면 **다른 탭·창·앱 위에도** 계속 떠 있음
- 기본 프리미엄: `AA` `KK` `QQ` `JJ` `AKs` `AKo` (팝업/옵션에서 자유롭게 변경)
- **🤖 자동 폴드 (옵션 · 기본 꺼짐)**: 지정한 핸드가 **아니면** 미리 폴드를 예약
- **🧠 GTO 자동 콜/폴드 (옵션 · 기본 꺼짐)**: **테이블 인원수(2~9명)에 맞춰**
  자동 전환되는 100BB 근사 차트로 콜/체크/폴드 (선택: 레이즈) 를 내 차례에 자동 실행

## 2. 파일 구조

```text
PokerNow-Hand-Alert/
├── manifest.json   # MV3 설정 (권한: storage + pokernow.club 호스트)
├── defaults.js     # 기본 설정·랭크 목록 (content/popup/options 가 공유)
├── poker.js        # 카드 파싱 · 핸드 정규화("AKs") · 족보 계산 (순수 로직)
├── gto.js          # GTO 근사: 인원수별 프리플롭 결정표 · 포스트플롭 에퀴티/팟오즈 판단
├── content.js      # ★핵심★ 게임 상태 감지·오버레이·BB계산·타이머·폴드
├── popup.html/js/css     # 툴바 팝업 (ON/OFF, 핸드 선택, 수동 Fold, 자동 폴드 설정)
├── options.html/js/css   # 13×13 스타팅 핸드 매트릭스
├── icon16/32/48/128.png
└── README.md
```

기본값은 [defaults.js](defaults.js) 한 곳에서만 정의합니다 — 세 화면이 같이 따라옵니다.
게임 화면 로직은 [content.js](content.js) 에, 카드/족보 계산은 [poker.js](poker.js) 에 있습니다.

## 3. 설치 (Load unpacked)

1. `PokerNow-Hand-Alert` 폴더를 저장
2. Chrome 주소창에 `chrome://extensions`
3. 우측 상단 **Developer mode** 켜기
4. **Load unpacked** → `PokerNow-Hand-Alert` 폴더 선택
5. PokerNow 게임 접속 → 화면 우측에 `♠ Hand Alert` 패널이 뜸

> 코드/manifest 를 수정한 뒤에는 **확장 새로고침(↻) + PokerNow 탭 F5** 를 꼭 같이 해주세요.

## 4. 사용법

- **오버레이 패널**: 헤더를 드래그해 이동, `–` 로 접기, `⧉` 로 팝아웃(항상-위 창).
- **Fold 하기**: 3가지 방법 — ①오버레이의 Fold 버튼 ②PokerNow 화면에서 `F` 키
  ③팝업의 Fold 버튼(다른 탭에 있어도 됨). 모두 **내가 직접** 눌러야 실행됩니다.
  세 경로 모두 같은 함수(`performFold`)를 지나가므로, **내 차례면 즉시 폴드**,
  아니면 **미리 폴드 예약 ↔ 취소 토글**이 되고 패널 라벨도 항상 실제 상태와 같습니다.
- **팝업(툴바 아이콘)**: 전체 ON/OFF, 프리미엄 핸드 체크, 알림음 on/off, 현재 패 표시, **자동 폴드 설정**.
  팝업의 모든 항목은 **바꾸는 즉시 저장**됩니다 (Save 버튼 없음). 옵션 페이지의 13×13 표만
  한꺼번에 고르는 화면이라 `저장` 버튼을 씁니다.

### 🤖 자동 폴드 (기본 꺼짐)

**켜는 법**: 팝업의 `🤖 자동 폴드` 스위치, 또는 오버레이 헤더의 `🤖` 버튼
(켜지면 아이콘이 초록색). 스위치를 바꾸면 **즉시 저장**됩니다.

**기본 방식 — 미리 폴드 예약 (`prefold`)**

1. 카드를 받는 즉시 홀카드를 본다.
2. **지정 목록에 없는** 핸드면 PokerNow 의 사전 액션 버튼을 대신 누른다.
   - `더 낼 돈 0 BB 면 체크` 옵션이 켜져 있으면 **Check/Fold** 를 우선 누른다
     (공짜로 볼 수 있는 상황은 체크로 살린다). 없으면 **Fold**.
3. 오버레이에 `🤖 폴드 예약됨 · 취소 안 하면 폴드` 가 뜬다.
4. 내 차례가 오면 **PokerNow 가** 예약대로 폴드한다.
   그 전에 `취소` 를 누르면 예약이 풀리고, 그 핸드는 다시 예약하지 않는다.

| 조건 | 동작 |
|------|------|
| 홀카드가 **지정 목록에 없음** | 미리 **폴드(또는 체크/폴드) 예약** |
| 홀카드가 **지정 목록에 있음** | 아무것도 안 함 (내가 직접 플레이) |
| 플롭 이후 | 기본은 아무것도 안 함 (`프리플롭에서만` 옵션을 끄면 이후에도 예약) |
| 예약 버튼이 없거나 안 먹었을 때 | 내 차례에 `N초` 뒤 직접 폴드 (폴백) |

**보조 방식 — 내 차례에 N초 뒤 (`turn`)**

사전 액션을 안 쓰고, **내 차례가 됐을 때** N초(즉시/1/2/3/5, 기본 **1초**) 기다렸다가 폴드합니다.
대기 중 오버레이에 카운트다운이 뜨고, **아무 곳이나 클릭하거나 키를 누르면** 취소됩니다.

**안전장치 (공통)**

- 누르기 **직전에 조건을 다시 확인** — 내 차례가 아니거나, 이미 폴드했거나,
  그 사이 카드가 지정 핸드로 바뀌었으면 누르지 않습니다.
- 한 스트리트에 **예약 1번 / 실행 1번** (중복 클릭 방지).
- 취소한 핸드는 그 핸드가 끝날 때까지 **다시 예약하지 않습니다.**
- 사전 액션 버튼 텍스트가 안 잡히면 `content.js` 의 `armPreFold()` 정규식
  (`check/fold`, `체크/폴드`) 을 실제 버튼 텍스트에 맞게 고치면 됩니다.
- **옵션 페이지**: 13×13 표에서 알림 대상 핸드를 자유롭게 지정 (대각선=페어, 위=수딧, 아래=오프수딧).

### 🧠 GTO 자동 콜/폴드 (기본 꺼짐)

자동 폴드 대신 **GTO 근사 전략**으로 콜/체크/폴드를 결정하는 모드입니다.
팝업의 `🧠 GTO 자동 콜/폴드` 스위치를 켜면 (자동 폴드 스위치도 자동으로 켜짐)
프리미엄 핸드 목록 대신 [gto.js](gto.js) 의 차트가 판단합니다.

**동작 방식**

1. 내 홀카드·포지션·보드·팟·콜 금액 + **이번 핸드 인원수**를 읽어 GTO 판단을 내립니다.
   - **프리플롭**: 인원수 티어(full 7~9 / six 5~6 / short 3~4 / hu 2) ×
     포지션(UTG/HJ/CO/BTN/SB/BB) × 핸드 → 폴드/콜/3벳 결정표
   - **포스트플롭**: 몬테카를로로 내 에퀴티 vs 상대 가정 레인지(상위 ~35%)를
     계산하고(기본 **1만 회**), **필요 에퀴티(콜금액/(팟+콜금액))** 와 비교해 콜/폴드
     (상대 레인지도 인원수에 따라 넓게/좁게 조정)
2. 오버레이에 **`GTO: 콜 46% vs 25%`** 처럼 권장 액션을 항상 표시
   (내 차례가 아니어도 보임).
3. **내 차례**가 오면 `N초`(자동 폴드 설정의 N초) 뒤 해당 버튼을 자동 클릭.
   그 전에 아무 곳이나 클릭/키 입력하면 취소됩니다.

| 설정 | 기본 | 뜻 |
|------|------|----|
| 범위 | 전체 | `프리플롭만` = 플롭 이후는 직접 |
| 레이즈 | 직접 | `자동` = 3벳/레이즈도 자동 클릭 |

> ⚠️ **레이즈 기본값은 "직접"** 입니다. GTO가 레이즈를 말하면 오버레이에 권장만
> 표시하고 자동으로 누르지 않습니다 (3벳 사이즈가 매번 달라서 실수 위험이 큼).
> `자동`으로 바꾸면 PokerNow의 기본 레이즈 버튼을 누릅니다.
>
> ⚠️ 차트는 **2~9인 캐시게임 · 100BB · 노 앤티 기준의 근사치**입니다.
> 인원수는 한 핸드에 카드를 받은 사람 수로 자동 판단합니다. 정확한 GTO는
> 레이크·스택·테이블 구성에 따라 달라지며, 레인지 문자열은
> [gto.js](gto.js) 의 `RANGES` 에서 바로 수정할 수 있습니다.
>
> ⚠️ 콜/레이즈까지 자동으로 누르면 **사이트 이용약관상 리스크**가 커질 수 있습니다.
> 개인 학습·연습 용도로만 사용하세요.

## 5. 감지가 안 될 때 (셀렉터 수정)

PokerNow HTML 이 바뀌면 [content.js](content.js) 상단의 셀렉터만 고치면 됩니다.

1. 게임 화면 **F12 → Elements**, 내 홀카드/버튼을 **우클릭 → 검사**
2. 실제 class 를 확인해 아래 배열 **맨 위**에 추가:
   - `HERO_CONTAINER_SELECTORS` — 내 자리 컨테이너
   - `CARD_SELECTORS` — 카드 요소
   - `FOLD_BUTTON_SELECTORS` — Fold 버튼
   - `BLIND_SELECTORS` — 블라인드 표시(콜 BB 계산용)
3. `chrome://extensions` **새로고침(↻)** + 게임 탭 **F5**

**디버그 로그**: 평소엔 꺼져 있습니다. 게임 탭 콘솔에서
`localStorage['pnha-debug'] = '1'` 실행 후 새로고침하면 `[PokerAlert]` 로그가 나옵니다
(끄려면 `localStorage.removeItem('pnha-debug')`).
현재 PokerNow 구조 기준값: 내 자리 `.table-player.you-player`, 카드 `.card-container`
(클래스 `card-s-<랭크>` + `card-<무늬>`), Fold `.action-button.fold`, 블라인드 `.blind-value`.

## 6. 권한 & 보안 (최소 권한)

| 권한 | 이유 |
|------|------|
| `storage` | 선택한 핸드·설정을 로컬 저장 (`chrome.storage.local`) |
| `host_permissions: https://*.pokernow.club/*` | **PokerNow 페이지에서만** 동작. 다른 사이트 접근 불가 |

- 데스크톱 알림/백그라운드 워커를 쓰지 않아 `notifications` 권한이 **필요 없습니다.**
- 네트워크 전송 없음, 계정/결제 정보 다루지 않음.
- 자동 액션은 **기본 꺼짐**이며, 끄면 게임 버튼을 자동으로 누르지 않습니다.
  자동 폴드를 켜면 폴드·체크를, GTO 모드를 켜면 콜/레이즈까지 자동으로 누를 수
  있습니다. 상대 카드를 보거나 게임 서버와 통신하지 않습니다.
- 사이트 이용약관은 각자 확인하세요. 개인 학습·연습 용도로 사용하시길 권합니다.

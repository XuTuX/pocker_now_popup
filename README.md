# PokerNow Hand Alert 🂡

PokerNow 테이블에서 **내 홀카드 2장을 읽어**, 미리 지정한 **좋은 핸드(프리미엄 핸드)** 가
들어왔을 때만 **Chrome 데스크톱 알림 + 알림음**을 울려주는 개인용 Chrome 확장 프로그램입니다.

> ⚠️ **중요 / 이 확장은 절대 게임을 대신 플레이하지 않습니다.**
> Fold / Call / Check / Bet / Raise 등 **어떤 버튼도 자동으로 누르지 않습니다.**
> 오직 **카드 감지 + 알림**만 합니다. 모든 게임 액션은 **사용자가 직접** 합니다.
> 별도 서버 없이 100% 로컬에서 동작합니다.

---

## 1. 무엇을 하나요?

1. PokerNow 게임 페이지에서 내 홀카드 2장을 감지합니다.
2. 카드를 표준 표기로 정규화합니다.
   - A♠ A♥ → `AA`
   - K♣ K♦ → `KK`
   - A♠ K♠ → `AKs` (수딧 / suited)
   - A♠ K♥ → `AKo` (오프수딧 / offsuit)
   - Q♠ J♠ → `QJs`
   - 10♠ 10♥ → `TT`
   - 랭크 표기: `2 3 4 5 6 7 8 9 T J Q K A`
3. 그 핸드가 **내가 지정한 프리미엄 핸드 목록**에 있으면 알림을 울립니다.
4. 같은 핸드에 대해서는 **한 번만** 알림이 울립니다 (새 핸드가 딜될 때까지 재알림 없음).

**기본 알림 핸드:** `AA` `KK` `QQ` `JJ` `AKs` `AKo`
(팝업 / 옵션 페이지에서 자유롭게 추가·제거할 수 있습니다.)

## 2. 파일 구조 & 각 파일의 역할

```text
PokerNow-Hand-Alert/
├── manifest.json   # 확장 프로그램 설정(권한, 스크립트 등록 등). MV3 기준.
├── content.js      # ★핵심★ PokerNow 페이지에서 카드 감지·정규화·알림음 재생.
├── background.js   # Service Worker. 데스크톱 알림(chrome.notifications) 담당.
├── popup.html      # 아이콘 클릭 시 뜨는 팝업 UI(빠른 핸드 선택, ON/OFF).
├── popup.js        # 팝업 동작 로직.
├── popup.css       # 팝업 스타일.
├── options.html    # 상세 설정 페이지(13×13 스타팅 핸드 매트릭스).
├── options.js      # 매트릭스 생성·저장 로직.
├── options.css     # 옵션 페이지 스타일.
├── icon128.png     # 확장 아이콘.
└── README.md       # 이 문서.
```

- **초보자용 요약**: 실제 감지 로직은 전부 `content.js` 에 있습니다.
  카드가 감지되지 않으면 대부분 `content.js` 상단의 **셀렉터 설정**만 고치면 됩니다 (아래 5번 참고).

## 3. 설치 방법 (Load unpacked)

1. 이 `PokerNow-Hand-Alert` 폴더를 컴퓨터에 다운로드/저장합니다.
2. **Chrome** 실행.
3. 주소창에 다음을 입력하고 Enter:
   ```text
   chrome://extensions
   ```
4. 오른쪽 위 **Developer mode(개발자 모드)** 를 **켭니다**.
5. **Load unpacked(압축해제된 확장 프로그램을 로드)** 버튼 클릭.
6. `PokerNow-Hand-Alert` 폴더를 선택합니다.
7. 목록에 **PokerNow Hand Alert** 가 나타나면 설치 완료.
8. [https://www.pokernow.club](https://www.pokernow.club) 에 접속해 게임 테이블에 들어갑니다.
9. Chrome 툴바의 확장 아이콘을 클릭해 팝업을 열고, 원하는 프리미엄 핸드를 선택 → **Save**.
10. 게임에서 카드가 딜되면 테스트해 봅니다.

> 💡 처음 한 번은 Chrome 이 데스크톱 알림 권한을 요청할 수 있습니다. **허용**해 주세요.
> macOS 라면 시스템 설정 → 알림 에서 Chrome 알림이 켜져 있어야 합니다.

## 4. 사용 방법 / 테스트 방법

### 팝업 (아이콘 클릭)
- **Status ON/OFF** — 확장 전체 켜기/끄기. OFF면 감지·알림을 하지 않습니다.
- **Current Hand** — 지금 감지된 내 홀카드와 정규화된 핸드 표시.
- **Premium Hands** — 자주 쓰는 핸드 체크박스. 체크 후 **Save**.
- **Sound / Desktop Notification** — 알림음·데스크톱 알림 개별 on/off.
- **More settings →** — 13×13 전체 매트릭스(옵션 페이지)로 이동.

### 수동 Fold 버튼 (팝업)
- 팝업의 빨간 **✋ Fold (수동)** 버튼은, **내가 직접 누를 때만** PokerNow 탭의
  Fold 버튼을 대신 눌러줍니다. 익스텐션이 스스로 판단해 폴드하지 않습니다.
- **다른 탭·다른 창에 있어도** 동작합니다: 열려있는 PokerNow 탭을 자동으로 찾아 폴드합니다.
  (프리미엄 알림이 안 울리는 안 좋은 핸드일 때, 굳이 게임 탭으로 돌아가지 않고 바로 폴드하는 용도)
- **키보드 단축키**: PokerNow 게임 화면이 포커스된 상태에서 **`F` 키**를 누르면 바로 폴드합니다.
  (채팅 입력창에 타이핑 중이거나 Ctrl/Alt 조합일 때는 발동하지 않습니다.)
  단축키 문자를 바꾸려면 [`content.js`](content.js) 상단의 `FOLD_HOTKEY` 값을 수정하세요 (`''` 로 두면 비활성화).
  > 참고: Chrome 확장의 "전역" 단축키는 Ctrl/Alt 조합만 허용되어, 다른 탭에서까지 통하는
  > 순수 `F` 단축키는 불가능합니다. 그래서 `F` 키는 **PokerNow 페이지가 포커스됐을 때만** 동작합니다.
  > 다른 탭에서 폴드하려면 팝업의 Fold 버튼을 사용하세요.
- **주의**: 내 차례일 때만 Fold 버튼이 존재하므로, 내 차례가 아니면 "버튼을 못 찾음" 메시지가 뜹니다.
- Fold 가 안 되면 [`content.js`](content.js) 상단의 `FOLD_BUTTON_SELECTORS` 에
  실제 Fold 버튼 셀렉터를 추가하세요 (F12 로 확인 → 배열 맨 위에 추가 → 확장 새로고침).

### 옵션 페이지 (169개 전체 핸드)
- 13×13 표에서 셀을 클릭해 알림 대상 핸드를 자유롭게 지정.
- 대각선 = 페어, 위쪽 = 수딧(s), 아래쪽 = 오프수딧(o).
- **프리미엄 기본값 / 전체 선택 / 전체 해제** 버튼 제공. 마지막에 **저장**.

### 테스트
1. PokerNow 테이블에 앉아 카드를 받습니다.
2. F12(개발자 도구) → **Console** 탭을 열어 두면 다음 로그가 보입니다:
   ```text
   [PokerAlert] Hole cards detected: A♠ K♥
   [PokerAlert] Normalized hand: AKo
   [PokerAlert] Hand allowed: true
   ```
3. `allowed: true` 이고 그 핸드가 선택되어 있으면 → 알림음 + 데스크톱 알림.

## 5. 카드가 감지되지 않을 때 (★ 가장 중요 ★)

PokerNow 의 HTML 구조는 업데이트로 바뀔 수 있습니다. 감지가 안 되면 아래 순서로 확인하세요.

1. 게임 화면에서 **F12** → **Elements** 탭 열기.
2. 내 홀카드(화면 아래 내 자리의 카드) 위에서 **우클릭 → 검사(Inspect)**.
3. 그 카드 요소의 **class 이름 / `data-*` 속성 / `aria-label` / 부모 요소**를 확인합니다.
4. 파일 [`content.js`](content.js) 를 열고, 상단의 **`[설정 구역 2] 카드 감지 셀렉터`** 부분을 수정합니다:
   - `HERO_CONTAINER_SELECTORS` — 내 자리(=hero)를 감싸는 컨테이너 셀렉터.
   - `CARD_SELECTORS` — 개별 카드 요소를 찾는 셀렉터.
   실제 화면에서 확인한 class/속성을 이 배열 **맨 위**에 추가하면 됩니다.
5. `chrome://extensions` 에서 이 확장의 **새로고침(↻)** 버튼을 눌러 반영.
6. 다시 게임 화면에서 F12 콘솔의 `[PokerAlert]` 로그를 확인.

> `content.js` 는 여러 감지 전략(class, data 속성, aria-label, 이미지 alt,
> background-image, 표시 텍스트)을 **자동으로 순서대로 시도**합니다. 그래도 안 되면
> 위처럼 실제 셀렉터를 배열에 추가해 주세요. 파서 함수는 그대로 두어도 됩니다.

### 디버그 모드
- `content.js` 최상단의 `const DEBUG = true;` 가 켜져 있으면 콘솔에 상세 로그가 출력됩니다.
- 조용히 쓰고 싶으면 `false` 로 바꾸고 확장을 새로고침하세요.

## 6. 알림음에 대한 참고 (Manifest V3)

Manifest V3 의 **service worker(background.js) 에서는 오디오를 직접 재생할 수 없습니다.**
그래서 이 확장은 알림음을 **content.js 안에서 Web Audio API 로 직접 생성**합니다
(별도 mp3 파일이 필요 없습니다). 데스크톱 알림만 background.js 가 담당합니다.

> 브라우저 자동재생 정책 때문에, 페이지에서 아직 아무 클릭도 하지 않은
> 첫 순간에는 소리가 막힐 수 있습니다. 테이블에서 한 번이라도 클릭한 뒤에는 정상 재생됩니다.

## 7. 보안 & 권한 설명 (최소 권한 원칙)

이 확장은 **꼭 필요한 권한만** 요청합니다.

| 권한 | 왜 필요한가 |
|------|-------------|
| `storage` | 선택한 핸드·on/off 설정을 로컬에 저장(`chrome.storage.local`). |
| `notifications` | 프리미엄 핸드일 때 데스크톱 알림 표시. |
| `host_permissions: pokernow.club` | **오직 PokerNow 페이지에서만** 스크립트가 동작. 다른 사이트 접근 불가. |

- **네트워크 전송 없음** — 카드 정보나 설정을 외부 서버로 보내지 않습니다. 전부 로컬에서 처리됩니다.
- **자동 플레이 없음** — 게임 버튼을 누르는 코드가 아예 없습니다.
- 개인 계정 정보, 비밀번호, 결제 정보 등을 다루지 않습니다.

## 8. 자주 묻는 질문

- **Q. PokerNow 규정에 문제 없나요?**
  A. 이 도구는 자동 액션을 하지 않는 "읽기+알림" 보조 도구지만, 사이트 이용약관은
  각 사이트마다 다를 수 있습니다. 사용 책임은 사용자에게 있습니다. 개인 학습·연습 용도로 사용하세요.
- **Q. 소리가 안 나요.** → 팝업의 Sound 가 켜져 있는지, 그리고 테이블에서 한 번 클릭했는지 확인.
- **Q. 알림이 안 떠요.** → OS/Chrome 알림 권한 허용 여부와 팝업의 Desktop Notification 토글 확인.
- **Q. 감지가 안 돼요.** → 위 5번(셀렉터 수정)을 따라 하세요.
